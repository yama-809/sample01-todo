# TODO アプリ 設計ドキュメント

**日付**: 2026-05-13  
**対象**: 個人用TODOウェブアプリ

---

## 概要

ブラウザで動作するシンプルな個人用TODOアプリ。サーバー不要。データはlocalStorageに保存。バニラHTML/CSS/JavaScriptで実装する単一ファイル構成。

---

## アーキテクチャ

### ファイル構成

```
todo/
└── index.html
```

1ファイルのみ。ブラウザでダブルクリックして直接開ける。外部依存なし。

### データモデル

localStorageキー: `"todo-app-tasks"`

```json
[
  {
    "id": "1715600000000",
    "text": "買い物をする",
    "completed": false,
    "tags": ["プライベート"],
    "createdAt": "2026-05-13T10:00:00.000Z"
  }
]
```

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | `Date.now()` による一意ID |
| `text` | string | タスク本文 |
| `completed` | boolean | 完了フラグ |
| `tags` | string[] | タグの配列（0個以上） |
| `createdAt` | string | ISO 8601形式の作成日時 |

## UIレイアウト

```
┌─────────────────────────────────────┐
│  📝 TODO アプリ                      │  ← ヘッダー
├─────────────────────────────────────┤
│  [タスクを入力...] [タグ入力] [追加]  │  ← 入力エリア
├─────────────────────────────────────┤
│  [すべて] [仕事] [プライベート] ...   │  ← タグフィルター
├─────────────────────────────────────┤
│  ☐ 買い物をする  [プライベート] [削除]│
│  ☑ 資料を作る   [仕事]       [削除]  │  ← タスクリスト
│  ☐ 本を読む     [趣味]       [削除]  │
├─────────────────────────────────────┤
│  残り 2件 / 完了 1件                 │  ← フッター統計
└─────────────────────────────────────┘
```

### 操作仕様

- **タスク追加**: テキスト入力 → タグ入力（任意、カンマ区切り）→ 「追加」ボタンまたはEnterキー
- **完了トグル**: チェックボックスクリック。完了タスクは打ち消し線スタイルで表示
- **削除**: 「削除」ボタンクリック（確認ダイアログなし）
- **タグフィルター**: タグバッジクリックで絞り込み。「すべて」ボタンで解除

## JavaScript ロジック

### 状態管理

グローバル変数2つのみ:

```js
let tasks = [];          // タスク配列
let currentFilter = '';  // 現在選択中のタグ（空文字=すべて）
```

### 主要関数

| 関数 | 役割 |
|---|---|
| `loadTasks()` | localStorageからタスク配列を読み込む |
| `saveTasks()` | タスク配列をlocalStorageに書き込む |
| `addTask(text, tags)` | タスクを追加してUIを更新 |
| `deleteTask(id)` | IDでタスクを削除してUIを更新 |
| `toggleTask(id)` | 完了フラグをトグルしてUIを更新 |
| `renderTasks()` | currentFilterに基づきタスクリストを再描画 |
| `renderTagFilter()` | 全タスクからタグを収集してフィルターバーを再描画 |
| `updateStats()` | 残り件数・完了件数フッターを更新 |

### エラーハンドリング

- localStorage読み込み失敗時（プライベートブラウジング等）: 空配列で初期化
- 空文字・空白のみのタスク追加: 無視（追加しない）
- タグの前後空白: trim()して保存
